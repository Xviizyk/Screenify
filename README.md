# Screenify

A Minecraft mod that lets you style in-game GUIs with real CSS — write a `.css` file, style your screens, similar in spirit to Vencord/BetterDiscord theming for Discord.

## Status

Early development. Project skeleton only — no styling engine yet.

## Platforms

- Fabric
- NeoForge

Built with [Architectury](https://docs.architectury.dev/).

## Building

```
./gradlew build
```
